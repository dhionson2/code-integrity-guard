# Code Integrity Guard 1.0.0 — release notes

Version 1.0.0 is the first stable release, published on 2026-11-21. The artifacts are available from [Maven Central](https://central.sonatype.com/artifact/io.github.dhionson2/code-integrity-guard-maven-plugin); see the [GitHub release](https://github.com/dhionson2/code-integrity-guard/releases/tag/v1.0.0) for the published installation details.

## Highlights

- Framework-independent core for contract and execution evidence.
- JUnit Jupiter testkit and declared Spring MVC authorization scenarios.
- PIT XML reader for an existing mutation report; CIG does not start PIT.
- Maven goals to prepare, seal, and audit evidence.
- Local JSON and HTML reports.
- Synthetic vulnerable/fixed Spring authorization example for local education and tests only.

## Requirements

- Java 21 or newer.
- Maven 3.10.1 or newer for the build and Maven plugin; the checked-in wrapper is configured for Maven 3.10.1.
- Consumers provide compatible test dependencies for the JUnit and optional Spring APIs they use.

## Limitations and security

CIG reports observed evidence. A passing test suite or audit does not prove an application secure and does not infer AI authorship. Version 1.0.0 does not cryptographically authenticate local evidence, aggregate reactor-wide evidence, or automatically invoke Maven Invoker integration tests. The testkit supports JUnit Jupiter.

The release review records limited maintainer acceptance of residual dependency findings for the audited release composition; those findings were not fixed by 1.0.0 and the acceptance does not cover consumer applications. See the dated [release readiness record](../release-readiness.md) and [supply-chain review](../supply-chain-review.md) for their scope and evidence. Consumers remain responsible for their dependency versions and application configuration. The educational Spring Boot example is excluded from the Maven Central publication and must not be deployed.
