# Code Integrity Guard 1.0.0 — release notes draft

Draft only. No artifacts are published. The release candidate includes modular Java 21 code, JUnit 5 execution/evidence integration, contract-based MockMvc authorization scenarios, a Maven audit plugin, JSON/HTML reporting, PIT XML parsing, and a synthetic Spring Security vulnerable/fixed demonstration.

The B7 PIT `partial` interpretation has been corrected against the official PIT 1.30.2 source. A real report with `partial="true"` is AVAILABLE when structurally complete, fresh in the current Maven session, free of unresolved error states, and within the configured expected class scope. The actual example reports 7/11 (63.636%); the 60% quality gate passes and the 70% gate fails as expected. A score is mutation-test strength evidence, not a security proof.

This is not approved for Maven Central. B8 remains blocked by unverified namespace/SCM ownership, incomplete NVD-backed SCA due to missing authorized NVD access, license compatibility review, and signing/publishing account setup. See `docs/release-readiness.md`.
