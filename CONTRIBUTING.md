# Contributing

Contributions are welcome. Use Java 21, preserve the dependency direction in `AGENTS.md`, add focused tests, and document security-relevant behavior.

1. Create a focused change and explain the requirement/behavior it addresses.
2. Run `./mvnw clean verify` (Windows: `mvnw.cmd clean verify`).
3. Do not add secrets, customer data, generated build output, or deploy/publish steps.
4. Keep intentionally vulnerable examples synthetic and test-only.
5. Submit changes with a clear summary, test evidence, and known limitations.

By contributing, you agree that your contribution is licensed under Apache-2.0.
